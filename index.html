SEC Sentiment Analyzer

Proyecto local con modelo Instruct

Descripción

Esta aplicación permite subir un archivo de la SEC y analizar el sentimiento del documento completo o de una sección específica como ITEM 1A, ITEM 7 o similar.

Características

  • Subida de archivos .txt, .md, .html o .htm
  • Análisis local con un modelo Instruct pequeño
  • Opción de analizar documento completo o una sección
  • Diseño simple para GitHub Pages o presentación

Uso

Ejecuta el archivo app.py localmente para abrir la interfaz.
